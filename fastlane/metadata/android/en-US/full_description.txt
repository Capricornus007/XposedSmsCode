XposedSmsCode is an Xposed/LSPosed module focused on verification code handling.

Core capabilities:
- Extract verification codes from incoming SMS.
- Copy detected codes to clipboard.
- Auto-fill codes in supported apps.
- Show notifications and optional Toast prompts for extracted codes.
- Keep verification records with type-based retention and export options.

Stability and compatibility:
- Android 7.0+ (API 24+).
- Designed for AOSP-like ROMs; compatibility may vary on heavily customized systems.
- Requires root with Xposed/LSPosed module activation and reboot.

F-Droid build note:
- F-Droid flavor enforces stricter network policy (HTTPS-only webhook, cleartext disabled).
